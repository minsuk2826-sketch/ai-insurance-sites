# AI보험 CRM 4.1

## 추가 기능
- 소개고객 관리
- 생일 7일 전 및 당일 알림
- 가족관계 메모
- DB 출처 관리
- 오늘 해야 할 전화
- 고객등급 VIP/A/B/C
- 업무 캘린더
- 보험증권 업로드 기능 제외

## 적용 순서
1. `01_최초1회_Supabase_SQL.sql`을 Supabase SQL Editor에서 한 번 실행합니다. 기존 데이터는 삭제되지 않습니다.
2. GitHub 저장소의 `04-crm` 폴더를 이 폴더 내용으로 덮어씁니다.
3. Vercel 배포가 끝난 뒤 새로고침합니다.

## 보안
`crm_policy.sql`은 로그인 사용자 접근 정책입니다. Supabase에 관리자 계정만 유지하고 공개 회원가입은 비활성화하세요.
