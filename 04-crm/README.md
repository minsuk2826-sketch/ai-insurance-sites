# AI보험 CRM 5.1 알림·가족관리 완성본

## 추가 기능
- 자동차보험 만기 자동 업무: D-30, D-15, D-7, 당일
- 생일 고객 자동 업무: 2주 전, 7일 전, 전날, 당일
- 가족 계약 트리: 기존 고객 연결 또는 직접 입력, 연결 고객 계약 자동 표시

기존 `04-crm` 폴더를 이 폴더의 파일로 덮어쓰세요. 기존 데이터 구조의 `profile_info` JSON을 사용하므로 추가 SQL은 필요하지 않습니다.


## CRM 5.4.1 추가 기능
- 휴대폰 번호 중복 고객 경고 및 기존 고객 바로 열기
- 이름·전화번호·보험회사·상품명·가족명 통합검색
- 상담 기록 작성 중 닫기 경고
- 자동차보험 만기 단계별 색상 표시
- 중요 고객 즐겨찾기 및 목록 상단 고정
- 고객별 최근 상담일과 경과일 표시
- 최근 상담순·자동차 만기순·생일순 정렬
- 대시보드 자동차 만기 및 이번 주 생일 숫자 요약

추가 Supabase SQL 없이 기존 데이터 구조에서 동작하도록 구성했습니다. 즐겨찾기는 현재 브라우저에 저장됩니다.


## 5.4.1 저장 UX 통일
- 고객 저장, 상담 기록, 다음 연락일, 결제·신분증, 계약, 가족 정보 저장 시 `저장 중...` 표시
- 저장 중 버튼 중복 클릭 방지
- 저장 완료 시 우측 상단 `저장되었습니다.` 알림 표시
- 결제정보·신분증 확인 영역의 저장 버튼 유지
