# AI보험 CRM 5.4.7

## 변경사항
- 결제정보와 신분증 관리 영역을 `고객 요약 · 상담 기록` 탭에서 제거했습니다.
- 해당 영역을 `계약 관리` 탭의 계약정보 목록 바로 아래로 이동했습니다.
- 상담 기록은 최근 3건 정도가 보이는 고정 높이 영역으로 변경했습니다.
- 네 번째 이전 기록부터는 같은 상담이력 영역 안에서 아래로 스크롤하여 계속 확인할 수 있습니다.
- 최근 3건에는 `최근` 표시를 추가했습니다.
- 상담 입력창, 상담 후 상태 변경, X로 닫기 기능은 그대로 유지됩니다.

## 배포
기존 GitHub 저장소의 `04-crm` 폴더를 이 폴더로 교체한 뒤 업로드하세요.


## CRM 5.4.8
- 마지막 상담 이후 30일이 지나면 오늘 할 일에 `미접촉 30일`로 자동 표시됩니다.
- 상담 후 상태 선택을 상담 입력창 우측 상단으로 옮겨 화면 중앙에서도 바로 보이도록 정렬했습니다.


## 5.4.10
- 대시보드 하단 `오늘 할 일` 고객 행을 더블클릭하면 고객 상세 관리 화면이 열립니다.
- 전화, 상담 열기, 완료 버튼은 기존 동작을 유지합니다.


## CRM 5.4.11 수정사항
- 고객 상세 관리 제목을 화면 중앙에 고정 정렬
- 닫기 버튼은 우측에 유지하면서 제목과 시각적 균형 개선
- 고객 상세 탭의 좌우 여백과 최소 너비를 확대하여 글자 잘림 방지
- 상담 상태 선택창 너비와 내부 여백을 확대하여 선택값 잘림 방지
- CSS/JS 버전 쿼리를 5.4.11로 변경하여 배포 후 캐시된 이전 UI가 보이는 문제 방지
- 5.4.10의 오늘 할 일 행 더블클릭 고객 상세 열기 기능 유지


## CRM 5.4.12
- 고객 상세 관리 제목을 화면 중앙에 강제 정렬
- 닫기 버튼은 우측 고정
- 상세 탭 글자 잘림 방지 및 중앙 정렬
- 상담 상태 선택값이 잘리지 않도록 폭 확대
- 오늘 할 일 행 더블클릭 고객 상세 열기 유지
