# AI보험 CRM 5.0 — 1차 수정본

## 이번 1차 반영 기능
- 신규 고객 등록을 팝업(모달) 방식으로 변경
- 생년월일을 연도 4자리 → 월, 월 2자리 → 일로 자동 이동
- 생년월일 입력 시 나이대 자동 계산
- 유입경로를 DB / 소개 / 기계약자 / 가망고객 / 랜딩페이지로 정리
- 랜딩페이지 선택 시에만 세부 랜딩 경로 입력란 표시
- 신규 고객 등록에서 다음 연락일·관심분야 제거
- 결제정보·신분증 확인 항목을 고객 상담기록 화면으로 이동
- 고객 상세 상담 화면에서 계약정보 관리
- 계약만료일·보험기간·납입기간 추가
- 기존 고객 데이터와 Supabase 연동 유지

## 적용 순서
1. GitHub 저장소의 기존 `04-crm` 폴더를 삭제하거나 통째로 덮어씁니다.
2. 이 ZIP의 `04-crm` 폴더 안 파일을 모두 업로드합니다.
3. Supabase에서 4.2 통합 SQL을 이미 실행했다면 SQL을 다시 실행하지 않아도 됩니다.
4. 아직 실행하지 않았다면 `01_최초1회_Supabase_SQL.sql` 전체를 Supabase SQL Editor에서 한 번 실행합니다.
5. Vercel 배포가 Ready가 된 뒤 브라우저에서 `Ctrl + Shift + R`로 강력 새로고침합니다.

## 확인할 항목
- 신규 고객 등록 버튼을 눌렀을 때 팝업이 열리는지
- 생년월일 입력 칸이 자동 이동하는지
- 나이대가 자동 표시되는지
- 랜딩페이지 선택 시 세부 경로 칸이 나타나는지
- 고객 상담 화면에서 결제정보·신분증 정보가 저장되는지
- 계약에 계약만료일·보험기간·납입기간이 저장되는지

## 보안 안내
카드 CVC와 주민등록번호 전체는 저장하지 마세요. 기존 관리자 전용 Supabase RLS 정책을 그대로 사용합니다.


## 3차 반영 기능
- 대시보드 우선순위 업무, 이번 달 실적, 주의 고객 요약
- 오늘 할 일 카테고리 필터, 긴급순/날짜순/이름순 정렬, 전화 바로가기
- 통계 메뉴: 최근 6개월 계약 실적, 고객 상태, 유입경로, 연령대 분포
- 기존 고객 및 계약 데이터를 그대로 사용하며 추가 SQL은 필요하지 않습니다.
