# AI보험 CRM 5.4.7

## 변경사항
- 결제정보와 신분증 관리 영역을 `고객 요약 · 상담 기록` 탭에서 제거했습니다.
- 해당 영역을 `계약 관리` 탭의 계약정보 목록 바로 아래로 이동했습니다.
- 상담 기록은 최근 3건 정도가 보이는 고정 높이 영역으로 변경했습니다.
- 네 번째 이전 기록부터는 같은 상담이력 영역 안에서 아래로 스크롤하여 계속 확인할 수 있습니다.
- 최근 3건에는 `최근` 표시를 추가했습니다.
- 상담 입력창, 상담 후 상태 변경, X로 닫기 기능은 그대로 유지됩니다.

## CRM 5.4.8
- 마지막 상담 이후 30일이 지나면 오늘 할 일에 `미접촉 30일`로 자동 표시됩니다.
- 상담 후 상태 선택을 상담 입력창 우측 상단으로 옮겨 화면 중앙에서도 바로 보이도록 정렬했습니다.


## 5.4.14
- 고객 상세 제목 실제 중앙 정렬
- 닫기 버튼 우측 고정
- 탭 글자 잘림 방지 및 너비 재배치
- 오늘 할 일 더블클릭 고객 상세 열기 유지


## 5.4.16
- 고객 상세 헤더에 뒤로가기 버튼 추가
- 고객 상세 제목을 정중앙 배치
- 상세 탭 글자 잘림 방지
- 오늘 할 일 더블클릭 고객 상세 열기 유지

- 상담 상태 선택창 너비 확대 및 글자 크기 조정으로 `현재 상태 유지` 한 줄 전체 표시


## 5.4.17
- 대시보드의 `놓치기 쉬운 일정 (약속일경과)`을 자동 계산하도록 변경
- 다음 연락일이 어제 이전인데, 약속일 당일 이후 상담 기록이 없는 고객만 표시
- 상담 기록을 남기면 해당 고객은 목록에서 자동 제외
- 오래 경과한 약속부터 우선 표시하고 고객 클릭 시 상세 화면 열기


## 5.4.18
- 대시보드 카드 제목을 `놓치기 쉬운 일정 (약속일경과)`로 고정 표시
- 사이드바 버전 표기를 5.4.18로 변경하여 덮어쓰기 적용 여부를 바로 확인 가능


## 5.4.20
- 날짜 입력란에서 20260805 또는 260805 입력 시 2026-08-05로 자동 변환
- Enter 입력 시 다음 입력칸으로 이동
- 계약일, 계약만료일, 자동차보험 만기일, 다음 연락일 등 날짜 필드에 적용


## 5.4.21
- 약속일 다음 날부터 상담기록이 없는 고객을 놓치기 쉬운 일정에 자동 표시
- 계약관리에서 자동차보험 여부, 차량번호, 만기일, 갱신 상태 입력
- 자동차보험 만기일을 대시보드/오늘 할 일과 자동 연동


## 5.5.0 통합 수정
- 대시보드 외 모든 메인 화면에 `← 뒤로`, `⌂ 홈` 버튼 추가
- 신규/수정 고객 등록창에 뒤로가기·홈·닫기 버튼 추가
- 고객 상세창에 뒤로가기·홈·닫기 버튼 추가
- 화면 이동 이력을 보관하여 뒤로가기가 직전 CRM 화면으로 복귀
- 약속일이 지난 뒤 해당 약속일 이후 상담기록이 없는 고객을 자동 표시
- 계약별 자동차보험 여부·차량번호·만기일·갱신상태 입력 및 대시보드/오늘 할 일 연동 유지
- 8자리/6자리 숫자 날짜 자동 변환 유지


## 5.5.2 검증 수정

- 다음 연락일이 지난 고객을 로컬 날짜 기준으로 계산해 `놓치기 쉬운 일정`에 표시
- 약속일 당일 이후 상담 기록이 없을 때만 표시
- 카드 제목에 현재 경과 고객 건수 표시
- 계약관리 자동차보험 계약·차량번호·만기일·갱신상태 입력 유지
- 모든 주요 화면 뒤로가기·홈 버튼 유지


## 5.6.2 수정사항
- 고객목록 검색·등급·상태·유입경로·정렬 필터를 PC 화면에서 한 줄로 배치
- 오늘의 우선순위 항목 더블클릭 시 해당 고객 목록으로 이동
