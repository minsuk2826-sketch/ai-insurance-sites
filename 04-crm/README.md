# AI보험 CRM 4.2

## 추가 기능
- 소개고객 관리
- 생일 7일 전 및 당일 알림
- 가족관계 관리
- DB 유입경로 관리 및 필터
- 오늘 해야 할 전화
- 고객등급 VIP/A/B/C
- 상담일·생일·계약일·자동차보험 만기 통합 캘린더
- 관리자 계정 1명만 고객정보에 접근하는 Supabase RLS
- 보험증권 업로드 제외

## 적용 순서
1. `01_최초1회_Supabase_SQL.sql` 전체를 Supabase SQL Editor에서 한 번 실행합니다.
2. GitHub 저장소의 기존 `04-crm` 폴더를 이 폴더로 통째로 덮어씁니다.
3. Vercel의 최신 배포가 Ready가 되면 CRM에서 강력 새로고침합니다.
4. 기존 로그인 계정으로 로그인한 뒤 고객 조회·저장·오늘 전화·캘린더를 확인합니다.

## 보안 안내
통합 SQL은 Supabase Auth에서 가장 먼저 생성된 계정 1개를 관리자 계정으로 자동 지정합니다. 현재 CRM 로그인 계정이 최초 계정인 경우 별도 수정이 필요 없습니다.
