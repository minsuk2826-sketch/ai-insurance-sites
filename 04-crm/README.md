# AI보험 CRM 4.0

GitHub 저장소의 `04-crm` 폴더에 이 폴더 안의 파일을 모두 덮어쓰면 됩니다.

## 포함 기능
- 고객관리 및 별도 신규등록 화면
- 상담기록 타임라인과 다음 연락일
- 계약 여러 건 등록 및 계약별 30일·90일·1년 관리
- 계약이 있는 고객만 표시되는 계약관리
- 자동차보험 보험사·차량번호·만기일·갱신상태
- 자동차보험 만기 30일·15일·7일 전 및 당일 알림
- 결제계좌·결제일·카드번호/유효기간·신분증 확인정보
- 오늘 할 일, 검색, 필터, 문자 보내기

## 최초 1회
`01_최초1회_Supabase_SQL.sql`은 이미 성공적으로 실행했다면 다시 실행하지 않아도 됩니다. `IF NOT EXISTS`가 포함되어 있어 재실행해도 기존 고객정보를 삭제하지 않습니다.
