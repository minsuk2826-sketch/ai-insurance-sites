[확인 완료]
1. 고객 상세 관리 상단의 '고객정보 수정' 버튼
   - 상세창 종료 후 해당 고객 수정 화면으로 이동
   - 이름, 연락처, 상태, 등급, 생년월일, 소개자, 가족관계, 상담 가능 시간 수정 가능

   - 만기일 미입력 시 저장 방지 안내
   - 저장된 만기일을 대시보드/오늘 할 일/캘린더에 반영

3. 공통 이동 버튼
   - 대시보드 및 주요 목록 화면: 뒤로 / 홈
   - 고객 등록·수정 화면: 뒤로 / 홈 / 닫기
   - 고객 상세 화면: 뒤로 / 홈 / 닫기

4. 정적 코드 검사
   - app.js JavaScript 문법 검사 통과
   - 필수 버튼과 입력창 ID 존재 확인
   - 버튼 이벤트 연결 확인
